Packing is where you author a component version and add resources to it. These guides cover
declaring resources and sources from different origins — GitHub archives, HTTP URLs, OCI
artifacts, SBOMs, and Git repositories — composing multi-component products, recording
ownership, and configuring a versioning scheme.
