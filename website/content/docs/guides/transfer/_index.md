Transfer guides move component versions from one OCM repository to another. Start
with [Transfer Component Versions]({{< relref "docs/guides/transfer/transfer-component-versions.md" >}})
for the default `ocm transfer cv` workflow, then pick the specialized guide for your
scenario: crossing an air gap, carrying Helm charts, uploading into vendor
registries, or configuring custom uploaders.
