Migrate guides update configuration written for older OCM versions so it keeps working
with current tooling. They cover replacing deprecated fallback resolvers with glob-based
resolvers, updating legacy `.ocmconfig` credentials to modern field names, and swapping the
deprecated `--upload-as` flag for an uploader configuration.
