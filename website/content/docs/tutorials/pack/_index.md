During the pack phase you compose software artefacts into a versioned OCM component. These
tutorials go beyond the basics and cover advanced construction patterns.

- [Create a Multi-Component Product]({{< relref "docs/tutorials/pack/advanced-component-constructor.md" >}}) — use the component constructor to build a product from multiple components with references
- [Working with HTTP Resources]({{< relref "docs/tutorials/pack/wget-http-resources.md" >}}) — fetch and bundle resources from HTTP endpoints
- [Working with SBOMs]({{< relref "docs/tutorials/pack/working-with-sboms.md" >}}) — attach a Software Bill of Materials as a typed resource inside a component version
