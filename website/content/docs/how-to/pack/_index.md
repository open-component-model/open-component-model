During the pack phase you describe your software artefacts as an OCM component version and push
it to a registry. These guides cover the most common construction tasks with the OCM CLI.

- [Add Resources from GitHub]({{< relref "docs/how-to/pack/add-resources-from-github.md" >}}) — include release artefacts directly from a GitHub repository
- [Add Resources from HTTP URLs]({{< relref "docs/how-to/pack/add-resources-from-http-urls.md" >}}) — fetch and bundle resources from arbitrary HTTP endpoints
- [Download Resources from Component Versions]({{< relref "docs/how-to/pack/download-resources-from-component-versions.md" >}}) — retrieve individual resources from a stored component version
- [Model Software Products]({{< relref "docs/how-to/pack/model-products.md" >}}) — compose multi-component products using component references
- [Add and Verify Ownership Information]({{< relref "docs/how-to/pack/add-and-verify-ownership.md" >}}) — opt a resource into ownership tracking and verify the record
- [Use the OCM CLI Container Image]({{< relref "docs/how-to/pack/container-image-usage.md" >}}) — run the OCM CLI without a local installation
